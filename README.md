# CATALOG

BPS Catalog 相关原型与需求文档（私有协作建议将仓库设为 Private）。

## 目录

| 目录 | 说明 |
|---|---|
| `bps-catalog-admin-v0.1/` | 管理端原型（商品库 / 资源位 / 分类）+ PRD |
| `bps-catalog-v0.1/` | 前台客户端原型 |

## 本地启动

### 管理端

```bash
cd bps-catalog-admin-v0.1
npm install
npm run dev
```

### 前台

```bash
cd bps-catalog-v0.1
npm install
npm run dev
```

# IAA 买变经营作战手册（中小团队可落地版）

- 版本 / 日期：v0.1 / 2026-07-30
- 适用：国内联盟变现 + 买量回收的 App（工具 / 内容 IAA 等）
- 定位：**规则经营，不依赖强算法**；实时只刹车，离线才换挡
- 风险态度：**宁可少赚，不可误熔断把盘打崩**

---

## 0. 汇报一页纸（给领导看）

### 我们怎么管住「不崩盘」

| 原则 | 落地动作 |
|------|----------|
| 两套账 | 预估账盯盘；结算账做主决策 |
| 三层干预 | L0 事故熔断 → L1 弱限速 → L2 次日换挡 |
| 样本门禁 | 没到最小样本，禁止关停/改价/改系数 |
| 单变量 | 同一天不既大改买量又大改瀑布 |
| 可回滚 | 任何上线改动必须有回滚步骤与责任人 |

### 上线顺序（强制）

1. **只观测 3～7 天**（告警，不自动动作）  
2. **半自动**：系统/表建议，人确认后执行  
3. **有限自动**：仅 L0 限速/单计划暂停（不得全账户一键停）  
4. 未满足门禁，禁止进入下一阶段

## 1. 角色与责任（出问题找谁）

| 角色 | 职责 | 可执行动作 | 禁止越权 |
|------|------|------------|----------|
| 投放负责人 | 计划健康度、预算、关停 | 降预算/暂停计划/换素材 | 不得改瀑布底价 |
| 变现负责人 | 填充、分层、广告位频控 | 调层/加兜底/降频 | 不得改 ROI 出价系数 |
| 数据负责人（可兼） | δ 对账、口径、看板 | 发布口径变更（需双人确认） | 不得当日改口径又让投放按新口径熔断 |
| 值班人 | 异常响应 | 执行 L0 分级动作 | 不得跳级「全停」 |

**变更双人制（建议）：** 涉及「总预算 −30% 以上 / 关停消耗 Top3 计划 / 瀑布大改 / 频控大改」→ 投放+变现各一人确认。

## 2. 口径字典（汇报与值班必须统一）

> 口径变更视为高风险变更：提前 24h 通知，并冻结当日强动作。

| 名词 | 定义（本手册默认） | 备注 |
|------|-------------------|------|
| 预估广告收入 | 展示事件 × 当次可用单价（Bidding 返回价或分层预估价） | 仅盯盘 |
| 结算广告收入 | 联盟/聚合报表确认收入（T+1） | 主决策 |
| 偏差系数 δ | 近 7 日「结算收入÷预估收入」的中位数 | 每日更新；异常日剔除 |
| 校准收入 | 预估收入 × δ | 用于校准 ROI |
| 校准 ROI（D0/24h） | 校准广告收入 ÷ 对应获客成本（同一归因窗口） | **主盯指标** |
| 填充率 | 有填充的请求 ÷ 广告请求 | 主广告位分别看 |
| 最小样本（计划日） | 消耗 ≥ **X 元** 且 转化/激活 ≥ **N 个** | X/N 见参数表，上线前必须填实数 |
| 最小样本（熔断窗） | 窗口消耗 ≥ **Y 元** 或 展示 ≥ **M 次** | 见参数表 |

**归因窗口（默认建议，可改但必须写死）：**  
买量看数 = **激活后 24h**；周决策补充看 D3/D7。

## 3. 参数表（上线前必须填成「你们的数」）

> 下列为**保守默认起点**，不是行业承诺值。上线前用近 14 日数据回放，改成自己的阈值，并在评审纪要签字。

| 参数ID | 参数名 | 保守默认起点 | 你们的定稿 | 负责人 |
|--------|--------|--------------|------------|--------|
| P01 | 目标校准 ROI（24h） | 1.0（打平） | | |
| P02 | 健康区间 | 目标 ±15% | | |
| P03 | 计划日最小消耗 X | 建议 ≥ 日均计划消耗的 30% 或 ≥500 元（取更合理者） | | |
| P04 | 计划日最小转化 N | ≥20 | | |
| P05 | 熔断窗时长 | 60 分钟 | | |
| P06 | 熔断窗最小消耗 Y | ≥200 元 | | |
| P07 | 熔断窗最小展示 M | ≥2000 | | |
| P08 | 填充率告警线 | 相对近7日同时段 −20% | | |
| P09 | 填充率熔断线 | 相对近7日同时段 −35%，且绝对值 <85% | | |
| P10 | 单计划消耗过速 | 1 小时消耗 > 日预算 40% | | |
| P11 | 冷却时间 | 同一对象 6 小时内不重复强动作 | | |
| P12 | 恢复迟滞 | 恢复须连续 2 个窗口回到安全区 | | |
| P13 | δ 告警 | δ 日波动相对7日中位 >25% | | |
| P14 | 主广告位填充底线 | ≥90%（日） | | |

**回放验收（上线门禁，必须做）：**  
用近 14 日日志/表，模拟本规则：  
- 误熔断次数（本不该停却停）  
- 漏熔断亏损（该停未停）  
两项都要有业务可接受结论，否则只停留在「只观测」阶段。

## 4. 每日计划作战表（投放主表）

**文件模板：** `docs/templates/每日计划作战表-模板.csv`  
**更新人：** 投放负责人  
**更新时间：** 每个工作日 10:00 前（基于昨日结算 + 今日预估）

### 4.1 字段说明

| 列 | 必填 | 说明 |
|----|------|------|
| 日期 | 是 | YYYY-MM-DD |
| 产品/包名 | 是 | |
| 渠道 | 是 | 巨量/广点通/… |
| 账户ID | 是 | |
| 计划ID | 是 | 最小管理单元 |
| 日预算 | 是 | |
| 当日消耗 | 是 | |
| 激活/转化数 | 是 | 与口径一致 |
| CAC | 是 | 消耗÷转化 |
| 预估广告收入 | 是 | A账 |
| δ | 是 | 当日沿用近7日中位 |
| 校准收入 | 是 | 预估×δ |
| 校准ROI_24h | 是 | 校准收入÷获客成本 |
| 样本是否达标 | 是 | Y/N（P03/P04） |
| 状态 | 是 | 冷启动/健康/观察/收缩/关停候选 |
| 建议动作 | 是 | 放/持/缩/停 |
| 是否执行 | 是 | 是/否 |
| 执行人 | 是 | |
| 回滚方式 | 缩/停必填 | 例如「恢复预算至 xxx」 |
| 备注 | 否 | 一行原因 |

### 4.2 状态机（禁止跳步乱判）

```
冷启动 --(样本达标)--> 观察/健康
健康 --(连续偏离)--> 观察 --> 收缩 --> 关停候选 --> 关停
任意状态 --(L0事故)--> 限速/暂停（记「事故动作」，不改状态机主路径）
```

| 状态 | 判定（须样本达标，否则一律冷启动/观察且动作=持） | 允许动作 |
|------|--------------------------------------------------|----------|
| 冷启动 | 未达 P03/P04 | **仅持**；禁止缩/停（除非 L0 事故） |
| 健康 | 校准ROI ≥ 目标 且落在健康区间或更好 | 持；可小幅放预算（≤+20%/日） |
| 观察 | 落在目标±15%，或仅 1 日低于目标 | **持** |
| 收缩 | **连续 2 日** 校准ROI < 目标−15% | 降预算 30%～50%（记回滚点） |
| 关停候选 | **连续 3 日** 明显低于目标−15% | 暂停计划；素材进观察名单 |
| 关停 | 关停候选经双人确认 | 关；7 日内同素材限制复开 |

### 4.3 动作红线（汇报用「纪律条款」）

1. 样本未达标：**禁止** 缩/停（L0 除外）  
2. 同一计划：**一日最多一次** 强动作（缩或停）  
3. **禁止** 用「小时预估 ROI」改出价系数  
4. **禁止** 一键暂停整账户（除非 P0 事故且负责人批准）  
5. 执行缩/停必须写回滚方式，否则视为未完成工单

## 5. 瀑布流 / 广告位检查清单（变现主表）

**文件模板：** `docs/templates/瀑布流配置检查清单-模板.csv`  
**更新人：** 变现负责人  
**节奏：** 每日快检 15 分钟；每周深检 1 次

### 5.1 每日快检（Pass/Fail）

| 检查项 | Pass 标准 | Fail 时动作（只允许弱动作） |
|--------|-----------|------------------------------|
| 开屏填充 | ≥ P14 | 加/确认无底价兜底；降低最高底价一层 |
| 插屏填充 | ≥ P14 | 同上 |
| 激励填充 | ≥ P14 | 同上；激励 Fail 优先于追 eCPM |
| 报错率/超时 | 无显著恶化（自定基线） | 查 SDK/并行度；并行过大则降并行 |
| ARPDAU 相对7日 | 跌幅可解释 | 只记录，大改放到周会 |
| δ 异常 | 未触发 P13 | 暂停相信预估强动作；改盯结算 |

### 5.2 广告位结构（标准件，上线对照）

| 广告位 | 必须具备 | 频控（保守默认，可改） | 禁止 |
|--------|----------|------------------------|------|
| 开屏 | Bidding + 瀑布 + 无底价兜底 | 自然启动展示；避免短时重复强弹 | 冷启动期禁止同时大加开屏又大加插屏 |
| 插屏 | 同上 | 最小间隔 60s；日上限建议先紧后松 | 禁止无间隔连弹 |
| 激励 | 同上 | 仅用户主动；奖励成本进毛利核算 | 禁止假激励、强制看完无法关闭的违规形态 |

### 5.3 瀑布周检（可改配置的唯一常规窗口）

**每周固定 1 次（建议周三），且当天买量侧只允许「持/弱缩」，不大放量。**

检查顺序（必须按序）：

1. 填充是否 ≥90%？否 → **只救填充**，本周不抬价  
2. 各层展示是否够（建议单层累计展示 ≥2000 再谈该层去留）？  
3. 长期无量层是否删除/合并？  
4. 收益占比与层数是否大致同向（高贡献平台多层，低贡献少层）？  
5. 是否只改 **一个** 主变量？是 → 记观察期 48h；否 → 打回  

**允许的单变量示例（一次只选一个）：**  
- 某一广告位增加 1 个中高价层  
- 某一广告位降低最高底价一层  
- 插屏日上限 −20%  
- 新增 1 家兜底平台（仅底层）  

### 5.4 变现变更工单（上线必填）

| 字段 | 内容 |
|------|------|
| 变更对象 | 产品 + 广告位 |
| 变更内容 | 一句话 |
| 预期 | 填充/ARPDAU/体验 |
| 回滚步骤 | 逐步写清（配置截图/备份名） |
| 观察期 | 默认 48h |
| 批准人 | 变现 + 值班（大改加投放） |

## 6. 熔断与干预（L0/L1/L2）——防崩盘核心

### 6.1 总原则

| 层级 | 时效 | 能否自动 | 允许做什么 | 禁止做什么 |
|------|------|----------|------------|------------|
| L0 | 30～60 分钟窗 | 半自动→有限自动 | 告警；单计划限速；单计划暂停 | 改 ROI 系数；改全盘瀑布；停全账户 |
| L1 | 3～6 小时滚动 | 建议+人工 | 降预算；暂停尾部计划 | 大改出价模型/系数 |
| L2 | T+1 结算后 | 人工 | 改系数、预算总盘、瀑布、频控 | 不凭当日小时噪声决策 |

### 6.2 L0 触发条件（须同时满足）

1. 窗口时长 ≥ P05  
2. 样本达标：消耗 ≥ P06 **或** 展示 ≥ P07  
3. 连续 **2** 个窗口异常  
4. 未处于该对象冷却期（P11）  

**异常（建议启用其中 2～3 条，不要全开）：**

- A. 填充触发 P09  
- B. 单计划消耗过速触发 P10  
- C. 预估 eCPM 相对近7日同时段跌幅过大（自定，建议 ≥40%）且填充未变好  

### 6.3 L0 动作阶梯（禁止跳级）

1. **告警**（值班确认）  
2. **限速**：该计划预算临时 −30%  
3. **暂停该计划**（仍禁止停账户）  
4. 写作战表「事故动作」+ 回滚点  

**恢复：** 达 P12（连续 2 窗安全）后，先恢复预算至原 70%，再下一日恢复满额（除非 L2 判定应关停）。

### 6.4 L1 / L2

- L1：校准预估（预估×δ）连续变差 → 只收缩尾部，不动头部放量计划  
- L2：次日结算开会 15 分钟，决定是否进入「收缩/关停候选」状态机

## 7. 对账与 δ（每天 10 分钟）

1. 导出昨日结算收入（分产品即可，有条件再分广告位）  
2. 汇总昨日预估收入  
3. 更新滚动 7 日 δ 中位数  
4. 若触发 P13：  
   - 当日 L1 强动作升级为「必须人工」  
   - 检查是否漏回传、时区、重复计量、活动日  

**财务口径冲突时：以结算账为准，预估账降级为参考。**

## 8. 周会模板（30 分钟）

1. 本周校准 ROI、消耗、量级（vs 上周）  
2. δ 是否稳定  
3. 填充是否曾跌破 90%，原因与动作  
4. 关停/收缩计划复盘：对了几个、误伤几个  
5. 下周 **唯一** 主变量是什么  
6. 风险与待确认  

纪要必须留下：主变量、回滚条件、责任人。

## 13. 给汇报人的口头稿（可选）

> 我们不靠复杂算法实时调价，而用「结算账做主舵、预估账做刹车」。  
> 线上安全靠四件事：样本门禁、分级熔断且只动到计划级、单变量变更、所有动作可回滚。  
> 先只观测与半自动，回放通过再谈有限自动；宁可慢，也不在噪声下把盘熔停。
